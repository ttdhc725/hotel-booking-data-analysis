# Hotel Booking Data Analysis Project

## Project Overview
This project analyzes hotel booking data using SQL Server and Power BI. The goal is to answer business questions about revenue growth, hotel type performance, customer trends, and parking demand.

## Tools Used
- SQL Server
- SQL
- Power BI
- Excel

## Business Questions
- Is hotel revenue growing by year?
- Which hotel type performs better?
- Is there enough evidence to increase parking lot size?
- What trends can be found in ADR, total nights, and discounts?

## Process
1. Imported Excel hotel booking data into SQL Server.
2. Combined yearly hotel booking tables using SQL UNION.
3. Joined booking data with meal cost and market segment tables.
4. Created revenue calculations using ADR and total nights.
5. Built an interactive Power BI dashboard.

## Key Insights
- Revenue increased from 2018 to 2019.
- 2020 data appears incomplete, so it should not be used alone for final business conclusions.
- Parking demand did not show strong enough growth to clearly justify expanding parking capacity.
